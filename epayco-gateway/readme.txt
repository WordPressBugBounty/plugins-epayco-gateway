**The official ePayco plugin for WooCommerce enables seamless payment processing for your online store.**

== Description ==

The official ePayco plugin provides smooth payment processing for your online store, allowing customers to complete their purchases using their preferred payment methods.

Installation is **simple and requires no technical knowledge**, so you can start selling immediately.

== Payment Methods ==

ePayco accepts Visa, MasterCard, American Express, Diners Club, SEPA, PSE (Bank Transfer), Cash Payments (Efecty, Gana, Punto Red, Red Servi, Su Red, Paga Todo, Acertemos, Gana Gana, Su Chance, Jer, La Perla), Daviplata, PayPal, SafetyPay, Davipuntos, Puntos Colombia (Coming Soon), and more directly in your store through the ePayco WooCommerce plugin, enabling payments from both mobile and desktop devices. In addition, ePayco supports 3D Secure v2.2.

== Why Choose ePayco? ==

== Installation ==

= Automatic Installation =

Automatic installation is very simple because WordPress handles the file transfer for you, so you do not even need to leave your browser. To automatically install the ePayco WooCommerce plugin, simply log in to your WordPress dashboard, go to the Plugins menu, and click **Add New**.

In the search field, type **"ePayco plugin for WooCommerce"** and click **Search Plugins**. Once you find our plugin, you can view details such as the version, rating, and description. Best of all, you can install it with a single click on **Install Now**, and then click **Activate**.

= Manual Installation =

1. Download the ZIP file from:
   https://github.com/epayco/Plugin_ePayco_WooCommerce?tab=readme-ov-file#requisitos
   or from the WordPress Plugin Directory:
   https://wordpress.org/plugins/epayco-gateway/
2. Go to the **Plugins** section and click **Upload Plugin**.
3. Upload the file, install, and activate the plugin.

Done!

= Installing This Plugin Will Not Slow Down Your Store =

If everything was installed correctly, you will find it in the **Installed Plugins** list in your WordPress dashboard. Simply activate it and continue with the integration and configuration of your ePayco account.

= ePayco Integration =

Log in to the ePayco dashboard using your credentials.

Next, go to the **Settings** module, click **Customizations**, and then select the **Secret Keys** category.

Approve your account so it can move to production mode and start receiving real payments.

= Configuration =

1. Log in to the ePayco dashboard using your credentials.
2. Go to **Settings > Customizations > Secret Keys**.
3. Enter your **P_CUST_ID_CLIENTE, P_KEY, PUBLIC_KEY, and PRIVATE_KEY**.
4. Test your store using Sandbox credentials.
5. Authorize your account to receive real payments.
